# Construction Business Website

A responsive multi-page construction company website featuring animated backgrounds, service showcase sections, project galleries, and modern UI layouts.

## Features
- Responsive Multi-page Design
- Animated Background Effects
- Service Showcase Pages
- Project Gallery
- Interactive Contact Form
- Modern UI Layout

## Tech Stack
- HTML
- CSS
- JavaScript
